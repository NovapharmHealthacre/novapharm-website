## Signals Data v3: licence, privacy and import boundary

- Primary publisher: [OpenAI Signals](https://openai.com/signals/), individual dataset [data page](https://openai.com/signals/data/) and [methodology/data download](https://openai.com/signals/data-download/).
- Official source archive: `https://cdn.openai.com/signals/data-download-csv.zip`. Publisher says data under **CC BY 4.0**, requiring attribution and indicating the dataset's limitations.
- Dataset version on the publisher page: **OpenAI Signals v3.0**, October 2026 update, data through September 2026. The data dictionary describes **24 CSV files**. Before any future import, verify the downloaded archive content, exact dictionary version, checksums, headers, row counts and permitted reuse.
- Local code accepts metadata for three initial, aggregate-only CSV families: topic/country/month shares, country/quarter per-capita ranks and work-related ask/do/express monthly shares. It does not ingest a ZIP, fetch external URLs, construct dashboards from unverified rows or access raw conversations.
- `share_of_messages` is a **differentially private, rounded share** and can have sampling variability; it is not an absolute count. Per-capita `rank` is ordinal, **lower number means higher relative use**, not revenue or adoption percent.
- Individual data excludes enterprise and Codex messages and must never be represented as global pharmaceutical market, staffing or medicine-level data. Inferred name labels must not be used for individual prediction or discrimination.
- Every future visual must include source/version, source-link, CC BY 4.0 citation, observed period, unit/grain, sampling/DP note, and warning when a country or subgroup is suppressed or incomparable. Expose no raw prompts, private user attributes, identities, clinical data or credentials.

## Shared web, iOS and Android behavior

1. The research index is rendered **within the existing protected, role-authorised Nova ML workspace**, not the public corporate site. Sources open as outbound external links; there is no anonymous endpoint, report content cache or downloaded proprietary PDF replica.
2. JavaScript `src/ai/intelligence-openai-signals.mjs` accepts only nonclinical research proposals, publicly aggregated data, zero incremental cost, no personal data/transfer and no autonomous decision. It returns **blocked** or **review-only**, and `executionEnabled: false` always. Its source and proposed data records are not trusted as permissions.
3. The Swift candidate `native/novapharm-intelligence-apple/NovaSignalsResearch.swift` and Kotlin candidate `native/novapharm-intelligence-android/NovaSignalsResearch.kt` mirror the identity/rights/cost boundary locally. Neither is an installed, signed app or independent policy-enforcement backend.
4. Optional future Whisper-like transcription requires approved model rights and exact version, consent and microphone permission only at the point of use, opt-in selected file, accurate locale/language handling, sensitive-content rejection and correction against original. Nothing automatically records or retains audio.
5. Optional training optimization and Triton require a benchmarked need, vendor-neutral profile, approved region and data rights, deterministic seeds, GPU quota, reliable rollback, model provenance, correctness-vs-baseline tests and a separately funded deployment authorization.
6. Any future agentic workflow starts in a read-only research sandbox. There is no side-effecting email, customer billing, sourcing, regulatory filing, inventory adjustment, import, cloud scaling or publication without an independently authenticated owner decision.

## Production and engineering release gates

- **Current owner configuration:** `config/intelligence/owner-production-constraints.json` has `productionSignoff: "not_granted"`, zero incremental infrastructure spending, no paid provisioning or public customer activation. No AWS/Azure operations permitted.
- **Required source CI:** Node deny and schema tests; protected portal typecheck and HIG/browser/role acceptance; Swift Package macOS tests; Kotlin CLI tests; CI paths include doc and rights changes; contact publisher skip is verified for these private-only changes.
- **Separate production acceptance:** exact live authenticated service image and source SHA, positive/negative role tests, documented data processing, licence and model rights, calibrated evaluations, native signing and physical-device acceptance, security/privacy/Quality approval, deployment and rollback evidence.
- A research-study result is not a clinical or scientific claim about a medicine and does not replace original documents, primary clinical or regulatory evidence.
- Every new research module must have a source register, study design limitations, permitted use, no implied causality and a release-maturity statement.

**Current maturity:** source-only integration candidate. No Signals dataset bytes imported; no live Signals API, Whisper endpoint, Triton GPU kernel, distributed training, user audio, app-store release or clinical AI service.
