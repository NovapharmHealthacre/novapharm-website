# NovaPharm Intelligence — global source intake integration (internal-only)

**Implementation stage:** 18 November 2026. This is a *stacked candidate PR based on #807* and reuses the immutable quarantine contracts from PR #812. It does not call live upstream APIs, create a dataset copy or release a mobile app.

## What is connected

The `createGlobalSourceIntakeEvaluator` factory composes the current five source adapter contracts, backend source-rights shape validation, exact country/tenant/purpose checks, country-specific response normalization and bounded 256 KiB raw-byte snapshot quarantine. The host URL is generated by the fixed-source adapter plan, never chosen by an app user. `fetchedAt` comes from the server clock; source `publishedOn` and observation periods must come from an independently verified source release record, not a guessed value.

The workflow accepts **offline in-memory JSON bytes** supplied by a trusted backend. It does not make HTTP requests and does not run in the mobile app. Evidence is separated from the raw-byte manifest: `manifest.digestSha256` identifies the exact sample bytes, while `evidence.responseSha256` identifies the parsed JSON representation used by the existing preview normalizer. These hashes are not guaranteed to match if byte formatting differs.

An internal mock permit demonstrates the boundary but is **not a real signed legal grant**. Every resulting manifest and evidence record has `canPublish: false`. Nothing may flow to customers until independently authorised source rights, clinical/commercial reconciliation, tenant security and data admission are implemented.

## Remaining production blockers

- Signed source-rights authority, provenance and commercial/AI/redistribution permissions per publisher and country; verified terms and publication schedule.
- A separate fixed-host network fetcher with bounded streaming, actual HTTP response headers, no redirect/SSRF, rate quotas, real 429 handling, source-specific schema detection and real-time revocation.
- Immutable encrypted storage with signed retrieval manifests, incremental ingest, completeness and failed-row accounting, independent QA and rollback.
- Actual country and pack identity reconciliation with medication reference data and clinical/territorial licences.
- Cognito MFA for at least two independent tenants, server ABAC/usage quotas, audit trail, app release entitlements and signed iOS/Android test builds.
- Official data feeds must be tested with live source evidence; mock tests prove only structural logic.
