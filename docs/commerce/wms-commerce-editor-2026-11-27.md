# WMS commerce editor — phase 2 candidate
Depends on #1284; retarget to main after its merge. This is a persistent private draft editor, not a live commerce publisher. Existing employee.products dashboard mounts the product master; API requires employee/admin session, CSRF and rate limit for writes. Writes default off and additionally require WMS_COMMERCE_DRAFTS_ENABLED=true and exact WMS_COMMERCE_EDITOR_ALLOWLIST membership. SQL migration 012 stores isolated revisioned drafts with audit and unique non-null GTIN. Source catalogue prices remain non-authoritative. Proposed stock and visibility are not actual stock or publication. Existing checkout, payments and public site remain unchanged. S1 new draft support does not assert an imported S1 catalogue. Before activating, verify persistent runtime, source files in deployment, migration, permissions, concurrency, UI and existing portal regression. Next: AWS publishing outbox/adapter, authoritative offer/stock reconciliation, verified media upload, public routing, SEO and Google feed; test before enabling. No production configuration or customer communications in this PR.
