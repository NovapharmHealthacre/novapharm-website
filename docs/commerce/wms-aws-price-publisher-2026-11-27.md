# WMS AWS price publisher — phase 3 candidate
Stacked on phase 2. Private IAM-only Lambda template; default disabled writes. It inspects an existing eligible Connective retail offer, returns its exact-byte SHA-256 revision, and accepts a price-only revision with expected hash, UUIDv4 idempotency key, trusted upstream workforce actor and saved draft revision. It preserves VAT treatment, quantity, expiry, approved product identity, label and media, and unrelated ledger attributes. The DynamoDB transaction updates only offerJson and inserts an immutable audit record, conditional on exact prior bytes. It never creates offers, touches orders, sends emails, changes Stripe objects, or increases stock. The existing public offer API and checkout already consume the ledger; separate live site and quote verification remain necessary. Exact checkout verifier parity is tested. Gross amounts not representable under the existing per-unit VAT rule are rejected rather than silently rounded.

Deployment: review IAM permissions and CloudFormation in isolated staging first, grant invoke only to a dedicated workforce backend role (not customer API), verify AWS account/region, no public Lambda URL. Portal bridge still required: authenticated server validates a saved draft, fetches current offer revision, presents current price and unchanged VAT for confirmation, invokes private worker using workload credentials with stable idempotency key, reads public offers and checkout quote, then reports actual publication status. Actor is a trusted upstream assertion; worker does not itself authenticate an end user. Do not enable production writes until the bridge, authenticated runtime and sandbox tests pass. No current live price was changed.

Nutraxin uses a separate SSM pricing authority and static product data; needs migration to a common revision-safe source without breaking its existing 19 SKU checkout. ESCO, S1, new SKU creation, media upload, supplier/physical stock authority and SEO feeds are separate work. This phase is deliberately limited to a price-only worker for existing approved Connective offers.
