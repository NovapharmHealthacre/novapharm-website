# WMS authenticated AWS price bridge
Stacked on #1297. This connects the existing employee product editor to the private price publisher via server-only IAM invocation. Both editor allowlist and a separate default-off price publication flag/scope are required. Browser submits only SKU, saved revision and reviewed offer hash; server obtains price/VAT from persisted draft. The deterministic request ID allows an identical retry without duplicate audit writes. ECS task role metadata is the only credential source; no browser secrets or arbitrary endpoints. The worker retains existing offer eligibility, VAT, supply and product fields. Only price is published, not any other edited draft field. A successful ledger readback is not a verified website/Stripe checkout; show these independently.

Deployment remains unverified: the existing AWS private staging portal ECS service has zero desired/running tasks. The correct unified API runtime needs a dedicated task role with lambda:InvokeFunction only for the named private publisher, isolated staging worker and test data before production invocation; validate signed requests against AWS, role scoping, flags, migration, session/CSRF and retry handling. Do not enable flags against production until reviewed. No production resource, price or payment setting is changed by this PR. Nutraxin SSM pricing, ESCO, S1, stock and photo/new SKU publishing remain pending.
