# NovaPharm Finance — corporate intelligence (SEC public EDGAR)

This read-only adapter fetches public Company Facts from the SEC for a validated CIK, with explicit organization/contact User-Agent. No token, SEC filer submission access or paid API. See https://www.sec.gov/search-filings/edgar-application-programming-interfaces and https://www.sec.gov/about/developer-resources . Configure a monitored organizational contact before any actual request; globally coordinate all SEC jobs and respect the SEC aggregate limit (currently 10 requests per second), honor rate limits, cache and back off. No recurring job enabled here.

Supported concepts include US GAAP and IFRS revenue, earnings, balance sheet and operating cash flow facts. Select exact concept, unit, start/end, filing date and accession. Preserve amendments separately. Never sum alternative revenue tags, combine currencies or annualize quarterly/YTD observations without a validated period model. As-of filtering uses filed date, not intraday filing acceptance time. This is not comprehensive filing coverage or a real-time stock quote feed. Unsafe integers or unsupported units are not normalized; missing values are not zero.

Run node --test scripts/test-finance-sec-corporate-intelligence.mjs. Fixtures are synthetic; no production retrieval verified. The adapter returns data in memory only. All stored Finance records must follow the AES-256 security standard in PR #1293: authorized server-side ingestion, KMS-backed encrypted storage, provenance, rights review, encrypted backups, no plaintext snapshot or payload logging. Coordinate with #1289, #1292 and #1293 before integrating authenticated application routes. No raw SEC data committed; no public route, paid resource, private data or existing commerce system modified.
