# NovaPharm Pure White primary — 23 November 2026

Owner-approved supersession of the former Royal Mineral White primary (`#FBFAEF`) with **Pure White (`#FFFFFF`)**. This is a NovaPharm web palette decision inspired by the clarity of Apple's light appearance; it is not a copy of proprietary Apple artwork or a claim of Apple affiliation.

## Current cross-estate neutral contract

| Role | Approved value | Use |
| --- | --- | --- |
| Primary light canvas | **Pure White `#FFFFFF`** | Website background, browser theme and light-brand canvas |
| Secondary neutral | Royal Porcelain White `#F8F7F3` | Cards, grouped sections and subtle surface hierarchy |
| Default text and neutral primary actions | Sovereign Black `#0B0B0E` | Headings, navigation and body copy |
| Decorative hairline | Porcelain Stone `#DEDCD5` | Subtle separation, never the only essential control boundary |

Healthcare crimson `#9D1B32`, Distribution garnet `#3D0B13` and Intelligence ultramarine `#2546D8` are **unchanged**, along with distinct status, link, focus and dark-appearance semantic colours.

## Source scope and validation

The source change covers the canonical neutral registers, shared CSS tokens, corporate/Portal/Status/Technology light themes, public site bundle, generated-route source metadata and PWA theme, checked-in relevant static HTML, Nutraxin product-page browser theme, living design guidance and their source-level regression checks. The governed logo-pack **tokens only** are updated together with their SHA-256 checksum entries; approved SVG/PNG artwork is preserved byte-for-byte.

**Safety exclusions:** Native iOS/Android raster imagery and its historic provenance remain unchanged pending independent asset review. The separately managed AWS Contact HTML source is preserved; shared web Contact CSS is revised, but this change does not authorize redeploying or modifying the protected Contact backend or source SHA. Historic audit/receipt files remain immutable.

## Release rules

No automatic site publication, account creation, checkout enablement, Contact API change, permissions change or additional AWS resources. Require the protected policy, brand checksum, public-page build/theme checks, accessibility/contrast checks, secure Portal & corporate browser suites, and a reviewed source-to-live publication gate before reporting `#FFFFFF` as live. Recheck the accepted primary canvas on both light and secondary grouped surfaces and ensure no loss of text/control contrast.

**Source approval is not production deployment.**
