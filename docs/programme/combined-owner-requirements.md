## Interpretation

- **Already complete and verified** means the stated scope has repository evidence and no broader production claim is implied.
- **Partially implemented** means real code/evidence exists but an applicable layer remains unfinished.
- **Not implemented** identifies repository work that has not yet been built; it is never hidden inside an owner blocker.
- **Externally blocked** requires a provider, credential, source, review, quota or environment outside repository authority.
- **Owner action required** requires an explicit owner identity, approval, account, cost, legal, regulatory or release decision.
