# Changelog

Material changes to the NovaPharm digital estate are recorded here. A release heading is created only for an immutable, approved deployment SHA.

## [Unreleased]

### Added

- Six-application TypeScript workspace with shared content, claims, security, accessibility, SEO, design-system and portal contracts.
- Azure Front Door Premium/WAF infrastructure contract, isolated application packaging, origin lockdown and deployment validation.
- Twenty-four-family component workbench, three reviewed creative directions and cross-browser evidence.
- Five-publication founder evidence model with verified publisher-link checks.
- Portal maturity catalogue covering all 54 governed modules, with 47 informational/read-only modules and seven dependency-blocked modules hidden.
- CodeQL, dependency review, CycloneDX SBOM, immutable GitHub Action pins, licence-policy validation and release changesets.

### Changed

- Public operating status now distinguishes active corporate and commercial-development work from regulated wholesale supply, which has not commenced.
- Polar Speed wording records the owner-attested relationship without transferring third-party licences, certificates or authorisations to NovaPharm.
- Browser acceptance derives protected route expectations from governed module release classifications.
- NIT and Founder execute their nonce-bearing JavaScript-state bootstrap during head parsing, eliminating constrained-start mobile hydration layout shifts while preserving complete scriptless navigation.

### Security

- Retired credentials remain prohibited; current-tree and full-history verification are release gates.
- Confidential portal, board and administrator content remains server-authorised and non-indexable.
- The npm and pnpm dependency graphs override vulnerable transitive `nanoid` releases to patched `3.3.18` and `js-yaml` 3.x to patched `3.15.1`; CI rejects drift in either temporary migration lock, and production-only and full dependency audits return zero known vulnerabilities.
- Application-owned portal route maps now determine login, password-change and logout navigation; API-supplied redirect strings are never trusted by browser clients.
- Non-password record fingerprints use purpose-separated keyed HMAC, internal AI audit records store neither prompt bodies nor reversible prompt fingerprints, and production fails closed without a sufficiently strong fingerprint/session key.
- HTML evidence extraction uses a structured parser, business-email validation is bounded and linear, controlled file reads use stable descriptors, and approved media acquisition is restricted to fixed reviewed sources and destinations.

No production release or deployment is represented by this unreleased entry.
