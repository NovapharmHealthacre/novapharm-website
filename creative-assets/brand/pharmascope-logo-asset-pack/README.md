# PharmaScope Logo Asset Pack

Complete production pack generated from the approved PharmaScope artwork supplied in chat.

## Included
- Primary, reverse-white and monochrome logo variants
- Web PNGs up to 8192 px wide
- SVG/PDF/EPS production containers
- Favicon, PWA and Apple icon sizes
- macOS iconset and ICNS where supported
- Social profile and Open Graph assets
- CSS/JSON brand tokens
- Pulse, Vector and Helix visual-system assets

## Important fidelity note
The supplied approved originals are raster PNG files. To avoid changing the geometry, the SVG/PDF/EPS outputs preserve the approved raster artwork inside scalable production containers rather than auto-tracing and altering the logo. If native path geometry is required for specialist large-format production, create a manual vector redraw from the approved source.
