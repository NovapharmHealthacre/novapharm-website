# Security Policy

## Reporting A Vulnerability

Please report a suspected vulnerability privately to `security@novapharmhealthcare.com`. Do not include patient information, customer records, credentials, private documents or exploit data in a public GitHub issue.

Include the affected route or component, observed behaviour, reproduction conditions and potential impact. NovaPharm will acknowledge receipt, triage the report and coordinate remediation and disclosure according to risk. Public disclosure should wait until a remediation plan has been agreed.

The public security contact is also published at `/.well-known/security.txt`. This policy does not create a bug-bounty programme or promise payment.

## Supported Versions

Security fixes are applied to the current `main` release candidate. Historical static releases remain rollback evidence and are not supported as independent application versions.
